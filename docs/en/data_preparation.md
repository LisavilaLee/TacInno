# Data preparation (UniVTAC)

TacInno is trained on UniVTAC demonstrations generated by the benchmark's scripted experts in the simulator used
for evaluation: 100 successful demonstrations per task (seeds tried in increasing order from 0, failures skipped).
Demonstrations 0-49 train the policy, 0-89 train the TacInno tokenizer, and 90-99 are held out for validation.

Final layout (paths are config keys; `data.data_root` defaults to `data/univtac`):

```
data/univtac/
├── raw/<task>/hdf5/<ep>.hdf5          demonstrations (cameras, joints, gel depth images and markers)
├── tactile/<task>/<ep:04d>.npz        per-episode tactile export                     (step 2)
├── codes/<task>/<ep:04d>.npz          tactile innovation codes of every frame       (step 3)
├── zarr_train/<task>/<task>_all.zarr  policy training data, head + wrist cameras     (step 1)
├── zarr_val/<task>/...                held-out episodes 90-99
├── head_cam/zarr_train/put_bottle_in_shelf/...   head-camera-only copy
├── cond/                              condition arrays and targets                    (steps 4-5)
│   ├── cond_stats.json
│   └── <split>/<task>/{fields,joints8,ep_start,aux_m,aux_mv,aux_ec,code_tgt,code_tv}.npy, meta.json
└── norm/univtac_6task/UniVTAC_<task>/  normalization statistics                       (step 6)
```

## 1. Demonstrations -> zarr

The pi0.5 data pipeline reads one zarr per task and split (frames 0 .. T-2 of every episode; the last frame has no
next action). Images are stored at 224 x 224 RGB; the state and the action are the 8 joint values (7 arm joints and
one gripper joint) written into the 120-D unified layout.

```bash
for t in insert_hole insert_tube lift_bottle lift_can pull_out_key put_bottle_in_shelf; do
  python tools/data/convert_univtac.py --base_dir data/univtac/raw_train --task_list $t --save_dir data/univtac/zarr_train/$t
  python tools/data/convert_univtac.py --base_dir data/univtac/raw_val   --task_list $t --save_dir data/univtac/zarr_val/$t
done
python tools/data/convert_univtac.py --base_dir data/univtac/raw_train --task_list put_bottle_in_shelf \
    --camera_type head --save_dir data/univtac/head_cam/zarr_train/put_bottle_in_shelf
```

`raw_train` / `raw_val` contain `<task>/demo/hdf5/<ep>.hdf5` for episodes 0-49 and 90-99 (symbolic links are fine).

## 2. Tactile export

```bash
python tools/data/export_tactile.py --src data/univtac/raw --out data/univtac/tactile --episodes 0-99
```

Per frame and gel: the indentation field `clip(28.5 - depth, 0, 6) / 3` on a 96 x 128 grid, the 63 marker positions,
their validity, 14 contact properties and the contact label (see
[`tacinno/datasets/tactile_fields.py`](../../tacinno/datasets/tactile_fields.py)).

## 3. Tactile innovation codes

Train the TacInno tokenizer (or download it) and export the code of every frame, see [tokenizer.md](tokenizer.md):

```bash
python tools/export_codes.py configs/tokenizer/tacinno-tokenizer_univtac-6task.py TOKENIZER_CKPT --out data/univtac/codes
```

## 4. Condition arrays and contact-state targets

```bash
python tools/data/make_cond.py --tactile-export data/univtac/tactile --out data/univtac/cond
```

Writes, aligned with the zarr frames, the tactile observations (2 gels x 3 channels x 96 x 128, float16), the joints,
the episode starts and the contact-state targets, plus `cond_stats.json` (joint mean / std over the training frames).
The bundled tactile statistics (`tacinno/datasets/stats/univtac_tactile_stats.json`: rest marker grid, sigma_u,
contact-property mean / std) are the ones of the released models.

## 5. Code targets

```bash
python tools/data/make_code_targets.py data/univtac/codes data/univtac/cond
```

Adds `code_tgt.npy` (the code of the window t .. t+15 of every frame) and `code_tv.npy` (window inside the episode).

## 6. Normalization statistics

```bash
python tools/data/compute_norm_stats.py configs/tacinno_vla/tacinno-vla_pi05_joint-17k_univtac-6task.py
```

z-score statistics of the state and the action per task (`norm/univtac_6task/UniVTAC_<task>/`). Every UniVTAC
config uses this six-task folder, so it is computed once. The released checkpoints carry their statistics in
`normalization/`; inference needs no data preparation.

## Real robot

The real-robot data (Franka FR3, one Xense gel, 10 Hz, four tasks) follows the same steps with
`configs/real_robot/tacinno-vla_pi05_20k_real-4task.py` (`data.data_root = data/real_robot`, domain prefix `Real_`); the
tactile frames are pre-processed on the robot workstation into the same indentation field and marker arrays, and the
right-gel input is a copy of the left gel. See [real_robot.md](real_robot.md).
