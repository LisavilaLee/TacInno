# Model zoo

The checkpoints are hosted on Hugging Face and the demonstrations on ModelScope.

| Repository | Content | Size |
|:--|:--|:--|
| [`Lisavila/TacInno-VLA`](https://huggingface.co/Lisavila/TacInno-VLA) (Hugging Face) | TacInno-VLA policies and TacInno tokenizers | about 53 GB |
| `TacInnoWeights/TacInno-UniVTAC-Demos` (ModelScope, coming soon) | UniVTAC demonstrations, 100 per task (HDF5) | about 112 GB |

Download a single checkpoint with the Hugging Face CLI, for example:

```bash
pip install -U huggingface_hub
hf download Lisavila/TacInno-VLA --include "sim/lift_can/*" --local-dir checkpoints
```

## TacInno-VLA, simulation (UniVTAC)

One policy per task, fine-tuned from $\pi_{0.5}$ on demonstrations 0 to 49 of the task. Success rates are on seeds
1000000 to 1000099 with twice the default action limit.

| Task | Checkpoint | Success (%) |
|:--|:--|:-:|
| Insert Hole | `sim/insert_hole` | 95 |
| Insert Tube | `sim/insert_tube` | 95 |
| Lift Bottle | `sim/lift_bottle` | 78 |
| Lift Can | `sim/lift_can` | 88 |
| Pull-out Key | `sim/pull_out_key` | 94 |
| Put Bottle | `sim/put_bottle_in_shelf` | 75 |
| **Average** | | **87.5** |

The training configs are in [`configs/tacinno_vla/`](../../configs/tacinno_vla). `tools/serve_policy.py` and the
evaluation client set the deployment of each released checkpoint automatically (see [evaluation.md](evaluation.md)).

Each policy directory holds `model.safetensors` (weights of the deployed model, about 7.5 GB),
`model_config.json`, `train_config.json` and `normalization/` (per-task normalization statistics). The tokenizer and the
two auxiliary heads are not part of the deployed model. The joint statistics and the tactile statistics the
released policies were trained with are bundled with the code (`tacinno/datasets/stats/`, returned by
`tacinno.datasets.stats_path`) and used by `tools/serve_policy.py` by default.

One checkpoint serves the four tasks (the language instruction selects the task). It is trained on the first 45 of
50 teleoperated demonstrations per task. See [real_robot.md](real_robot.md) for the deployment.

## TacInno tokenizer

| Checkpoint | Training data | Used for |
|:--|:--|:--|
| `tokenizer/sim` | six UniVTAC tasks, demonstrations 0 to 89 | code targets of all simulation policies |
| `tokenizer/real` | four real-world tasks, first 45 demonstrations | code targets of the real-world policy |
| `tokenizer/ablation/no_conditioning` | as `tokenizer/sim` | w/o conditioning |
| `tokenizer/ablation/image_only` | as `tokenizer/sim` | vision-only conditioning |
| `tokenizer/ablation/action_only` | as `tokenizer/sim` | analysis of the conditions (actions alone) |
| `tokenizer/ablation/two_frame_t15` | as `tokenizer/sim` | two-frame code ($t$ and $t{+}15$) |

Each tokenizer directory holds the weights (`model_012000.pt`, step 12000), the training arguments
(`args_000000.json`) and the action normalization (`cmd_stats.pt`). The tokenizer reads frozen
`facebook/dinov2-base` image features, which are not duplicated.

## Demonstrations

`TacInnoWeights/TacInno-UniVTAC-Demos` holds 100 demonstrations for each of eight UniVTAC tasks, generated by the
benchmark's expert scripts in the same simulator used for evaluation; the paper uses six of them. Each episode is one
HDF5 file with the head and wrist camera images, the joint states and the readings of both tactile sensors. [data_preparation.md](data_preparation.md) converts them into training data.
